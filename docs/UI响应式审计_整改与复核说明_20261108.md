## 1. 复核结论纠错（重要）

### 1.1 P0-2 是真缺陷，此前「根因证伪」的判断是错的

送审评审稿（工作区 `UI审计报告_评审结论与优化方案_20261108.md`）曾把 P0-2 判为「根因证伪、降为 P1-存疑」。该结论建立在**未加载 Bootstrap 的内存页面探针**上，不成立。

真实页面 CDP `CSS.getMatchedStylesForNode` 的结果：

```
origin=user-agent  selector=div                              -> block
origin=regular     selector=[hidden]                         -> none !important
origin=regular     selector=.sidebar-scrim                   -> none
origin=regular     selector=body.sidebar-open .sidebar-scrim -> block
```

即 **`bootstrap.min.css` 的作者层全局规则 `[hidden]{display:none!important}`** 压过了 `components.css` 的 `body.sidebar-open .sidebar-scrim{display:block}`。原报告说「`!important`」是对的，但把它归给 Chromium UA 样式表是错的。

真实页面实测（390px）：打开抽屉后 `#sidebarScrim` 为 `display:none`、尺寸 `0×0`；移除 `hidden` 属性后立即变成 `block` / `390×788`。

**处置**：P0-2 恢复 P0 级，按原报告方案 B 修复（移除 `base.html` 遮罩的 `hidden` 属性，显示态由 CSS 单源控制），**没有使用 `!important`**。修复后打开 `display:block`、点遮罩关闭回到 `none`，Esc / 汉堡按钮逻辑不变。

> 教训：判断「UA 样式 vs 作者样式」必须用真实页面的完整样式表，不能用 `page.setContent()` 的内存页面做隔离实验——后者缺少项目实际加载的第一方 CSS。

### 1.2 其余评审结论仍然成立

P0-1 成立但漏了 `app.css:2015` 外层元凶、且「必然复发」过强；P1-3 是设计意图误判；方法描述「九档实测」失实；影响面低估。以上均以本次实测为准，详见送审评审稿 §3（该稿 §3.2 已被 §1.1 推翻，其余章节有效）。

### 2.1 一处对原整改建议的实测修正

送审方案曾计划「去掉硬编码 `min-width`，改列保底宽度」。实测 1180px 下 `.table-responsive` 可用宽度只有 **882px**，去掉 `min-width` 会让 12 列挤进去、省略号更多（正是方案风险 R1）。仓库里已验证的核价页范式本来就是**保留 `min-width` + 容器内横向滚动**，因此按该范式执行：

```
容器 clientWidth=882 / scrollWidth=1200（可横向滚动）
表格宽度=1200px（列宽预算不变，12 列全部可达）
documentElement 溢出=0
```

被标记的 5 个宽表在桌面端不再有「相对视口吸附」的表头（横向滚动容器不竖向滚动时 sticky 不生效），换取整页不溢出；**未标记的表格保持 `overflow:visible`，表头吸附零回归**；`@media print` 下宽表容器恢复 `overflow:visible`，打印不裁列。

## 4. 明确未做 / 裁剪项（需产品决策）

1. **关键列省略号**：1180px 下表格宽 1200px、容器 882px，长文本列仍以省略号收尾，需**在卡片内横向滚动**查看完整值。彻底消除需重排列宽预算或允许单元格换行，会改变台账信息密度，属产品决策。
2. **悬浮按钮滚动期遮挡**：固定定位按钮在用户滚动时仍会短暂覆盖右侧内容；完全消除需改为可收起式或随内容滚动，属交互设计决策。
3. **字号下限的三类显式例外**（已写进 `records/test_ui_font_size.py` 的 allowlist，例外之外新增小字号会在 CI 失败）：
   - `static/css/customer-review.css`（43 处 0.64–0.74rem）：高密度核价/复核数据标签，统一到 12px 会破坏紧凑布局；
   - `*print.html` / `*pdf.html`（12 处 7–8.5pt）：打印 / PDF 排版按纸张单位衡量，不适用屏幕像素口径；
   - `knowledge_base/document_detail.html` 的脑图折叠标记（`font-size:10px`，行内标注 `ui-font-exempt`）：SVG 按固定坐标绘制，放大会溢出节点圆圈。
   另有 `font-size:0`（视觉隐藏技巧）与第三方 `*.min.css`，守卫自动跳过。**除上述例外，模板内联与自研 CSS 的屏幕正文已全部 ≥12px。**
4. **行内文字链接热区**：首页 3 个 `.home-panel__link` 高 16–20px，WCAG 2.5.8 (AA) 对 inline link 有豁免，未强制撑到 44px。
5. **`hidden` 属性单源化**：核查全部 11 处，JS 均用 `.hidden` 属性切换，与 Bootstrap `[hidden] !important` 一致，无需改动。`copilot/panel.css:508`、`app.css:1883`、`daily-record.css:785` 三处 `[hidden]` 补丁为冗余，其注释「类选择器会盖掉 UA 规则」归因错误（Bootstrap 已有 `!important`），仅记为代码卫生项。
6. **P2-2 / P2-3**：转数据专项，含历史数据归一与生产样本统计，不与样式改动同批发布。
7. **P1-3**：卡片模式是否隐藏次要列属产品决策，本次维持既有设计。
